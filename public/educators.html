№ 01

Built like a game. Structured like a lesson.

More than half of US states now require a personal-finance course to graduate. Tycoon turns that requirement into something students ask to keep playing — and every mechanic doubles as a debrief prompt.

A.

Hindsight, automated

When a student panic-sells an asset, Tycoon quietly keeps a ghost of it. Twelve months later: "Your old index fund would be worth $4,200 today (+38%)." Counterfactual learning, without you building the spreadsheet.

B.

The Year-in-Review

Every January the game stops and shows each student their own annual report — market gains, passive income earned, and what their net worth would have been if they had never invested. A built-in reflection assignment.

C.

One world, whole class

The Daily Challenge gives everyone the same seeded economy and the same character — identical market, identical events. Differences in outcome are pure decision-making. The leaderboard makes the debrief run itself.

D.

Checks for understanding

Risk & diversification quizzes appear right when students first browse stocks. A plain-English glossary, mortgage maths shown line-by-line before every purchase, and an EQ course round out the teachable surface.

№ 04

Questions teachers ask.

What do students actually do in the game?
Each turn is one month. Students manage a salary and budget, choose investments (index funds to real estate, with mortgages amortised properly), respond to life events, invest in education and side hustles, and balance energy, stress, and happiness. A run to financial freedom takes roughly 2–6 class periods depending on difficulty.
How does the class code work?
You receive one code (for example LINCOLN-HS-2026). Students open the game in a browser, enter the code once, and the full version unlocks on that device for the year. No accounts, no roster upload.
What about student privacy?
The game requires no student names, emails, or accounts. Progress is stored locally on each device. Optional cloud backup exists but is off by default and never required for class use.
Does it map to curriculum standards?
Tycoon covers budgeting, compound growth, diversification and risk, credit scores and borrowing, insurance decisions, income taxes on windfalls, career investment, and inflation — the core strands of state personal-finance standards and the NGPF course arc. Pair any unit with the in-game glossary and quizzes for assessment.
Is there homework potential?
The Daily Challenge resets every 24 hours with a fresh seeded world — same for every player on Earth. It takes about 15 minutes and produces a shareable result card, which makes it a naturally self-grading bell-ringer or homework loop.
Can I try before buying?
Yes — the free demo is the real game for the first 36 simulated months, which comfortably covers a trial unit. No sign-up needed.
