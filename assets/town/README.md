# Freedom Square art workflow

Blender 5.2.1 LTS is installed at `/Applications/Blender.app`. No account, subscription, Blender MCP server or remote asset service is required.

The original artwork is generated by `scripts/build-town-assets.py`. Editable sources:

- `freedom-square.blend`: detailed shopfronts, facade trims, balconies, landscaping, street furniture and fountain.
- `town-character.blend`: articulated character, with Idle, Walk, Run, Serve, Wave and Celebrate animation tracks. Ankle joints keep trainers level; grip anchors support the cup handoff. Optional `Fem_*` parts (long hair, side hair, fringe, ponytail, earrings, lips, bust, skirt) and `Masc_*` parts (beard, cap) hang off the Head, Torso and Hips pivots; the game shows or hides them per resident (`components/town/townResidents.ts`), so one model serves every neighbour, guest, teller and player.
- `town-vehicles.blend`: a hatchback (`Car`) and a delivery van (`Van`) with named `Wheel`/`Hub` objects the game spins, `carPaint` recoloured per vehicle and `lamp` materials lit in rain.

Rebuild from the project directory:

```sh
'/Applications/Blender.app/Contents/MacOS/Blender' --background --python scripts/build-town-assets.py
'/Applications/Blender.app/Contents/MacOS/Blender' --background --python scripts/build-town-extras.py
'/Applications/Blender.app/Contents/MacOS/Blender' --background --python scripts/refine-town-character.py
```

Run all three in that order for a from-scratch rebuild: the base script makes the city and the plain character, the extras script adds the sex-specific parts to the character source and builds the vehicles, and the refinement script re-exports the character with its animation tracks. Editing only the extras (parts or vehicles) needs extras + refine; the city file is untouched by those two.

Exports go to `public/models/town`. The city uses Draco mesh compression (about 1.1 MB); the animated character with its optional parts is about 334 KB; the Draco-compressed vehicles are about 100 KB. The game loads these files only when the city opens. It creates resident colour variations, lighting, water particles and the character-following camera at runtime.

All city and character models were created for this project; no purchased or externally sourced character meshes were used. Draco's decoder is distributed with its Apache 2.0 licence in `public/decoders/draco/LICENSE`.

Blender is an asset creation tool. Walking, camera orbit/zoom, the touch joystick, collision limits, transactions and saves remain in the game code. No paid Blender Studio or Adobe plan is needed for this version. Mixamo is an optional future source of more varied motion; it has not been used here.

The refinement script can also run by itself against the existing character source. It replaces animation tracks without rebuilding the city. Runtime walk/run rates match the clips’ stance travel; service movement routes around the cart, frames the handoff, then returns to the saved viewpoint. Camera presets and the opening-journey badge persist in the normal game save.

## Runtime additions and handover

The bank/café interiors and furnishings are authored in the town runtime modules, not baked into `freedom-square.blend`. Seated poses (benches and café chairs), carried cup attachment, steam, order labels, queues, rain/puddles, pigeons, bunting, traffic behaviour and the synthesized soundscape are also runtime work (`townResidents.ts`, `townTraffic.ts`, `townLife.ts`, `townAtmosphere.ts`). Editing the Blender city alone will not change them. See [HANDOVER.md](../../HANDOVER.md) for the current source map and release status.

The latest exact export sizes are 1,163,764 bytes for `freedom-square.glb`, 333,824 bytes for `town-character.glb` and 100,568 bytes for `town-vehicles.glb`. Keep the Serve/Wave/Celebrate clips and grip/ankle joints when replacing animation. `build-town-assets.py` regenerates base assets; run the refinement script afterward to retain the refined character tracks. Preserve edited source files before regeneration. No asset rebuild is needed for documentation or café economic changes.

Current art/code remains local and uncommitted; a fresh git clone does not yet include all of it. Physical-phone performance and more precise hand/foot contact remain open. No Blender, Higgsfield or Mixamo signup is required for this handover.
